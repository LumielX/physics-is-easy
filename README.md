# Physics is Easy

เว็บไซต์เรียนฟิสิกส์ ม.4–ม.6 ที่เน้นให้ผู้เรียน **เข้าใจจริง** ผ่านการทดลองด้วยตัวเองในเบราว์เซอร์
ครบทั้ง 19 บทตามหลักสูตร สสวท. พร้อมเครื่องจำลอง 27 ตัวที่คำนวณจากสมการฟิสิกส์จริง

**Created by Narawit Luekhajon**

## เริ่มต้นใช้งาน

```bash
npm install          # ติดตั้ง dependencies
npm run dev          # เปิดเซิร์ฟเวอร์สำหรับพัฒนา → http://localhost:3000
npm run build        # สร้างเวอร์ชันสำหรับใช้งานจริง
npm start            # รันเวอร์ชันที่ build แล้ว
```

ต้องใช้ **Node.js 20 ขึ้นไป** (พัฒนาและทดสอบบน Node 24)

### คำสั่งอื่น ๆ

```bash
npm run typecheck    # ตรวจชนิดข้อมูลทั้งโปรเจกต์ด้วย TypeScript
npm test             # รัน unit test ทั้งหมด (physics engine + ความถูกต้องของเนื้อหา)
npm run lint         # ตรวจสไตล์โค้ด
npm run models:build # สร้างโมเดล 3 มิติใหม่ด้วย Blender
```

## หลักการออกแบบที่สำคัญ

เหตุผลเบื้องหลังการตัดสินใจทุกข้อบันทึกไว้ใน [DECISIONS.md](./DECISIONS.md) สรุปหลัก ๆ คือ

1. **เครื่องจำลองคำนวณจากสมการจริง** — `lib/physics-engine/` เป็น TypeScript ล้วน
   ไม่ import React หรือ three.js เลย จึงทดสอบเทียบกับผลเฉลยที่คำนวณมือได้โดยตรง
   ถ้าตัวเลขบนหน้าจอผิด เทสต์จะแดงก่อนเสมอ

2. **เนื้อหาเป็นข้อมูลที่มีชนิดกำกับ** — บทเรียนแต่ละบทเป็น object ที่ตรงกับ schema
   `Chapter` ลืมใส่แหล่งอ้างอิงหรืออ้าง simulator ที่ไม่มีอยู่ → `tsc` ฟ้องตอน build
   ไม่ใช่ตอนผู้ใช้เปิดเว็บ

3. **เร็วมาก่อนสวย** — เนื้อหาทุกบทถูกสร้างเป็น HTML ตั้งแต่ตอน build (SSG)
   JavaScript มีเฉพาะส่วนที่โต้ตอบได้จริง และ three.js โหลดเมื่อกด "3D" เท่านั้น

4. **3D เฉพาะที่จำเป็น** — ใช้กับบทที่แนวคิดเป็นเรื่องของปริภูมิสามมิติจริง ๆ
   และถ้าอุปกรณ์ไม่รองรับหรือเฟรมเรตต่ำ ระบบจะสลับกลับ 2D ให้อัตโนมัติ

5. **ไม่ต้องล็อกอิน** — ความคืบหน้าเก็บใน localStorage ของเครื่องผู้ใช้เอง
   ไม่มี backend ไม่มีข้อมูลส่วนบุคคล และล้างได้เองจากหน้าตั้งค่า

## การเพิ่มบทเรียนใหม่

1. สร้างไฟล์ใน `content/physics/<grade>/` ตาม schema `Chapter`
2. import เข้าไปใน `content/physics/index.ts`

เท่านั้น — เมนู, หน้ารวมบทเรียน, ดัชนีค้นหา, sitemap, หน้าสูตร และหน้าแบบทดสอบ
จะอัปเดตตามเองทั้งหมด เพราะทุกอย่างอ่านจาก `lib/content/registry.ts` ที่เดียว

## การเพิ่มเครื่องจำลองใหม่

1. สร้าง component ใน `components/simulators/labs/`
2. เพิ่ม metadata ใน `lib/simulators/registry.ts`
3. เพิ่ม dynamic import ใน `components/simulators/loader.tsx`
4. อ้างอิง id นั้นใน `simulators: []` ของบทเรียน

เทสต์ใน `tests/content.test.ts` จะตรวจให้ว่าทั้งสามที่ตรงกัน

## แหล่งอ้างอิงเนื้อหา

เนื้อหาทุกบทอ้างอิงหนังสือเรียนรายวิชาเพิ่มเติมวิทยาศาสตร์และเทคโนโลยี ฟิสิกส์ เล่ม 1–6
ของ **สสวท. (IPST)** เป็นหลัก ร่วมกับตำรามาตรฐานระดับมหาวิทยาลัย (Halliday–Resnick–Walker,
Young & Freedman) และค่าคงตัวจาก **CODATA 2018 (NIST)**
รายการอ้างอิงเต็มอยู่ท้ายทุกบทเรียน
